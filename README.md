# 🎨 Nexus Frontend (Client Application)
**Lead Developer:** Supriya Unde  
**Technologies:** React, HTML5 Canvas, Tailwind CSS / Vanilla CSS, Axios

---

## 📌 Your Roadmap from the PRD
1. **Authentication UI**: Login & Register pages with role selection (Parent, Teacher, Clinician).
2. **Assessment Canvas**: HTML5 interactive canvas capturing real-time stylus/touch stroke events (, y, t, p$).
3. **Adaptive Task Engine**: Presentation of reading, phonology, and motor tasks adapted to child age band (5-7, 6-8, 8-10, 10-12).
4. **Developmental Report Dashboard**: Visualizing ML scores, evidence levels (Elevated Concern, Supporting, Developing, Monitor), and SHAP feature importance charts.
5. **PDF Export**: Downloadable clinician summary report.
